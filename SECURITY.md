# Security policy

## Supported versions

SliceSeeker is an early-stage self-hosted project. Security fixes are provided
for the latest released version only.

## Reporting a vulnerability

Open a public GitHub issue. Include the affected component and version,
reproduction steps, impact, and any suggested remediation.

Do not include exploit payloads, credentials, private media, or other sensitive
details in the issue. If those are needed to reproduce the problem, say so in
the issue and ask for a private contact channel.

Please do not test against systems you do not own or operate. This project does
not run a hosted SliceSeeker service.

Licensing and copyright-compliance concerns are not security vulnerabilities;
report those through the repository's public issue tracker.
